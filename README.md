# Puneet Verma — Academic Pages

Academic website: https://puneetvrma.github.io/

Uses the original Academic Pages / Minimal Mistakes theme, layouts, sidebar and styles without a custom UI.

Content is in `_pages/`; navigation is in `_data/navigation.yml`; profile details are in `_config.yml`.

The academic content is based on the supplied CV and excludes professional employment and associated government projects. The original CV is not uploaded. Bibliography links are Google Scholar title searches.

GitHub Pages publishes from `master` / root. Unused template example pages and collections are excluded through `_config.yml`.
